MVP003 - INSTALLATION AND QUICK START
=====================================

This file describes how to install the `MVP003` package.

PREREQUISITES
-------------
- Python 3.11 or newer.
- Internet access to install dependencies from `requirements.txt`.
- `tkinter` support.

Linux note:
- on some distributions, `tkinter` must be installed separately.
  Debian/Ubuntu example:

     sudo apt install python3-tk


QUICK INSTALL ON LINUX / MACOS
------------------------------
1. Enter the `MVP003` folder.
2. Run:

   bash install.sh

3. Launch the GUI:

   bash run.sh

You can also activate the environment manually:

   source .venv/bin/activate
   python src/gui_app.py


QUICK INSTALL ON WINDOWS
------------------------
1. Open PowerShell or `cmd` inside the `MVP003` folder.
2. Run:

   install_windows.cmd

3. Launch the GUI:

   run_windows.cmd


MANUAL INSTALLATION
-------------------
1. Enter `MVP003`.
2. Create the virtual environment.
3. Activate it.
4. Install dependencies:

   python -m pip install --upgrade pip setuptools wheel
   python -m pip install -r requirements.txt

5. Launch the GUI:

   python src/gui_app.py


OPTIONAL VERIFICATION
---------------------
Quick verification:

   python -m unittest discover -s test -p 'test_*.py'
   python -m compileall hydranet src test

The installers also support full verification:

- Linux / macOS:

     RUN_CHECKS=1 bash install.sh

- Windows:

     install_windows.cmd -RunChecks
