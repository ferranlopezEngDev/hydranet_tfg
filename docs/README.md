# Hydranet Workspace Docs

Esta carpeta documenta la capa comun del repositorio versionado:
el gestor de MVPs, el flujo de trabajo esperado y el proceso para
crear nuevas versiones como `MVP004`, `MVP005`, etc.

## Documentos de esta carpeta

- [MVP Manager](mvp_manager.md): uso diario de la tool `mvp.py`,
  arquitectura, comandos disponibles y formato de `mvp.json`.
- [Nuevo MVP](creating_a_new_mvp.md): proceso recomendado para crear,
  documentar, instalar y validar un nuevo MVP.

## Alcance

Estas guias no sustituyen la documentacion interna de cada MVP.
Su objetivo es explicar la capa comun del workspace:

- como descubrir versiones,
- como instalar y ejecutar cada una,
- como dar de alta una nueva,
- y como mantener sincronizada la metadata del gestor.
